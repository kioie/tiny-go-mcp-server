# Branding

Official visual identity for **Tiny Go MCP Server**.

## Assets

| File | Use |
|------|-----|
| [`docs/assets/logo.png`](../docs/assets/logo.png) | Primary logo (full artwork) |
| [`docs/assets/banner.png`](../docs/assets/banner.png) | README / docs header banner |
| [`docs/assets/icon.png`](../docs/assets/icon.png) | Square icon (512×512) for listings and favicons |
| [`.github/social-preview.png`](../.github/social-preview.png) | GitHub social preview (1280×640) |

All assets are PNG with a light neutral background matching the logo artwork.

## GitHub repository

1. **README** — banner is embedded at the top of [`README.md`](../README.md).
2. **Social preview** — upload [`.github/social-preview.png`](../.github/social-preview.png) under **Settings → General → Social preview** (one-time, requires repo admin).

## External listings

When a directory asks for an icon or logo, use the raw GitHub URL:

```
https://raw.githubusercontent.com/kioie/tiny-go-mcp-server/main/docs/assets/icon.png
```

(or `logo.png` / `banner.png` as appropriate)

- **Smithery** — server Settings → upload [`docs/assets/icon.png`](../docs/assets/icon.png)
- **MCP Registry / mcp.so** — use icon URL or upload when the form supports it
- **Launch posts** — link to the banner or logo URL above

## Naming

- **Project name:** Tiny Go MCP Server
- **Short name:** tiny-go-mcp
- **Library package:** tinymcp

Do not rename or recolor the mascot without updating all official assets together.
